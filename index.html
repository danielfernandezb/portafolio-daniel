Un poco sobre mí / 02

Tecnología con sentido de negocio.

Ingeniero de sistemas y desarrollador web con experiencia conectando tecnología, operación y comercio digital.

Desde Cartagena desarrollo y mantengo sitios web y tiendas online. He trabajado con Shopify y Shopify Plus, WordPress, WooCommerce y Elementor Pro, además de interfaces con React y Angular.

En e-commerce gestiono productos y colecciones, mantengo el catálogo y configuro checkouts y pasarelas de pago como Wompi. También tengo experiencia práctica con PHP, bases de datos SQL, APIs REST, VPS, Linux, DNS y soporte de sitios en producción.

Busco oportunidades remotas y tengo flexibilidad para coordinar horarios con equipos de otras zonas.
